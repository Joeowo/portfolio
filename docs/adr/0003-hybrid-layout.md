# ADR-0003: 采用混合布局策略

## 状态

已采纳 (2026-05-27)

## 上下文

Portfolio Platform 有 6 个模块，需要统一的布局框架。

常见选项包括：
1. **经典侧边栏布局** — 左侧固定导航，右侧内容区滚动
2. **顶部导航布局** — 顶部固定导航栏，内容区全宽
3. **统一布局** — 所有页面使用同一种布局

## 决策

**采用混合布局策略** — 不同模块使用不同布局：

| 模块类型 | 布局方式 | 说明 |
|----------|----------|------|
| 创作类（素材库、作品编辑器） | 沉浸式全屏 | 无侧边栏，内容占据全部空间 |
| 管理类（管理后台） | 侧边栏布局 | 左侧固定导航（160-200px） |
| 其他（认证、模版选择、网页管理） | 顶部导航或独立布局 | 根据页面特性定制 |

### 路由与布局映射

```
/auth          — 独立布局（居中卡片）
/studio        — 沉浸式全屏
  /assets      — 沉浸式全屏 + 顶部工具栏
  /works       — 沉浸式全屏 + 侧边抽屉
/publish       — 顶部导航
  /templates   — 大图预览 + 小图列表
  /pages       — 网格卡片布局
/admin         — 侧边栏布局
```

## 理由

| 因素 | 说明 |
|------|------|
| 场景适配 | 创作页面需要沉浸感，管理页面需要多入口导航 |
| 视觉重点 | 沉浸式布局让内容（图片、作品）成为主角 |
| 设计一致性 | 同类型页面布局一致，不同类型可差异化 |
| Nothing 风格 | "让最重要的元素浮动在背景上"，全屏更符合 |

## 后果

### 正面

- 每种场景的最优体验
- 创作类页面视觉冲击力更强
- 管理类页面导航清晰

### 负面

- 需要维护多套布局组件
- 页面切换时布局变化可能产生跳动感
- 共享组件需要适配多种布局

### 缓解措施

- 抽象共享布局组件（`<ImmersiveLayout>`、`<SidebarLayout>`、`<MinimalLayout>`）
- 统一过渡动画，减少跳变
- 共享组件设计时考虑多布局兼容
